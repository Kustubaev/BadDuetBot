# Бот совместимости веществ

Тестовый Telegram-бот: пользователь выбирает два вещества, затем получает статус и текст из CSV.

## Запуск

1. Установите Python 3.11 или новее.
2. В папке проекта выполните:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   python bot.py
   ```

3. Убедитесь, что в `.env` есть строка `BOT_TOKEN=...`.

## Формат данных

Данные хранятся в `interactions.csv` в UTF-8. У каждой строки четыре поля:

```text
substance_1,substance_2,reaction,explanation
```

`reaction` принимает одно из значений:

- `Есть потенциальная польза`
- `Нейтрально`
- `Есть риск`
- `Нет данных`

Порядок веществ значения не имеет. Бот не показывает варианты без заполненной строки и не разрешает выбрать вещество дважды. При старте бот проверяет пустые пояснения, повторы и некорректные статусы.

Текущие записи — демонстрационные: их нужно заменить согласованными данными перед использованием с пользователями.

## Деплой на Railway

Railway запускает этот проект как постоянный worker: бот получает обновления Telegram через long polling. Публичный домен и порт для такого бота не нужны.

1. Создайте новый приватный репозиторий на GitHub и загрузите в него содержимое этой папки. Файл `.env` не добавляйте: он уже исключён через `.gitignore`.
2. Откройте [Railway: Deploy from GitHub](https://railway.com/new/github), войдите в аккаунт и выберите созданный репозиторий.
3. После создания сервиса откройте раздел `Variables` и добавьте:

   ```text
   BOT_TOKEN=ваш_токен_из_BotFather
   ```

   Значение берите из локального `.env`, но сам файл в Railway не загружайте.
4. Railway автоматически установит зависимости из `requirements.txt` и запустит `python bot.py`. Команда запуска уже задана в `railway.toml`.
5. Откройте `Deployments` → последний деплой → `View Logs`. Успешный запуск содержит строку о начале polling. Затем отправьте боту `/start` в Telegram.

Каждый `git push` в ветку, подключённую к Railway, будет запускать новый деплой. При замене тестовых данных достаточно изменить `interactions.csv`, закоммитить файл и отправить изменения в GitHub.
