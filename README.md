# Бот совместимости веществ

Тестовый Telegram-бот: пользователь выбирает два вещества, затем получает статус и текст из CSV.

## Запуск

1. Установите Python 3.11 или новее.
2. В папке проекта выполните:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   python bot.py
   ```

3. Убедитесь, что в `.env` есть строка `BOT_TOKEN=...`.

## Формат данных

Данные хранятся в `interactions.csv` в UTF-8. У каждой строки четыре поля:

```text
substance_1,substance_2,reaction,explanation
```

`reaction` принимает одно из значений:

- `Есть потенциальная польза`
- `Нейтрально`
- `Есть риск`
- `Нет данных`

Порядок веществ значения не имеет. Бот не показывает варианты без заполненной строки и не разрешает выбрать вещество дважды. При старте бот проверяет пустые пояснения, повторы и некорректные статусы.
